# Provenance and external dependencies

- The mask geometry, named components, preview materials and project-specific export/build scripts were created for this project. No downloaded mask model, logo, texture pack or third-party source package is included.
- The `.blend` was reconstructed in a fresh scene using only those mask meshes and the single-Root attachment rig. No character head, original glasses mesh, game texture, linked library or packed image is included.
- The rig's attachment transform and the symbolic game asset/parameter names are retained for compatibility with the game's glasses accessory slot. Their presence does not include or grant rights to the game's assets.
- Blender, Unreal Engine, Stellar Blade and CNS are separate dependencies and are not bundled. Obtain them from their respective providers and follow their applicable terms. This repository is not affiliated with their creators.
- The [Stellar Blade Modding Guide](https://github.com/Stellar-Blade-Modding-Team/Stellar-Blade-Modding-Guide/wiki/Materials) was consulted for the material workflow. No guide text or third-party implementation is vendored here.

No license has been selected for the original project files yet. This notice is provenance information, not an open-source license. Any separately provided game screenshot remains distinct from the original model and code.
